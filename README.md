# Project GL 『이클립스 세븐』 첫 플레이 프로토타입 v0.2

3D 액션 JRPG · 3인칭 백뷰(명조 방식). index.html 을 브라우저로 열면 바로 실행됩니다.
외부 라이브러리 없이 자체 WebGL 엔진(js/gl3d.js)으로 그리므로 인터넷 연결 없이도 동작합니다.

## v0.2 변경점
- 2D 탑뷰 → 3인칭 백뷰 3D
- 마우스 이동 = 카메라 회전, WASD = 카메라 기준 이동 (클릭 시 마우스 고정, Esc로 해제)
- 공격은 카메라 앞쪽 가까운 적에게 자동 조준 (관측 중에는 보스 매듭 우선)
- 전멸기 흑백 연출 중에도 매듭·약점·위험 범위는 색 유지

## 파일 구조 (핵심 코드 분리)
| 파일 | 역할 |
|---|---|
| index.html | 진입점, 스크립트 로드 순서 |
| css/style.css | 화면 스타일 (3D 캔버스 + UI 오버레이) |
| js/config.js | **모든 수치** (수치표와 같은 값) — 밸런스는 여기만 수정 |
| js/utils.js | 수학/판정 도구 |
| js/input.js | 공통 조작 체계, 0.5초 홀딩 판정, 마우스 카메라 |
| js/combat.js | 피해 공식, 파쇄 게이지, 그로기, 관측, 예고 공격, 이펙트 |
| js/party.js | 이안·바렌·케이, 평타·강공격·스킬·궁극기, 태그, 조력, 소프트 락온 |
| js/enemies.js | 파편체·침식자·파쇄손·집행 수호자·시차 분신 |
| js/boss.js | 인과 보스 템푸스 3페이즈, 시간 역류, 전멸기 |
| js/stage.js | 필드 3웨이브 → 포털 → 보스전 흐름 |
| js/gl3d.js | 자체 WebGL 엔진 (로우폴리 도형, 바닥 그리드, 데칼) |
| js/render.js | 3인칭 카메라, 3D 장면, 체력바·숫자 오버레이 |
| js/ui.js | HUD, 지도, 타이틀·일시정지·결과 화면 |
| js/main.js | 게임 루프, 화면 상태 |
